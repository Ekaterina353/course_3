# Проект: Поиск вакансий с подключением БД #

## Технологии использованные: ##

1. Python
2. PostgreSQL
3. psycop2

## Функциональность: ##   

### Парсинг: ###
Вакансию парсит с помощью библиотеки requests и сохраняет данные о вакансии в список словарей.
### Сохранение данных в базу данных: ###
Данные по каждой вакансии сохраняются в таблицы PostgreSQL через библиотеку psycopg2.
### Фильтрация и сортировка данных: ###
Библиотека Filter используется для фильтрации и сортировки данных из базы данных.
### Получение средней зарплаты и вакансий с выше средней зарплатой: ###
Вакансию с выше средней зарплатой выдает функция get_vacancies_with_higher_salary.
### Поиск вакансий по ключевому слову: ###
Функция get_vacancies_with_keyword используется для поиска вакансий, в названии которых содержатся переданные в метод слова.
### Получение списка компаний и количества вакансий у каждой компании: ###
Вакансию с выше средней зарплатой выдает функция get_companies_and_vacancies_count.
### Получения общего количества вакансий: ###
Функция get_all_vacancies используется для получения общего количества вакансий.

## Установка проекта: ##

### Установить зависимости из файла requirements.txt: ###
pip install -r requirements.txt

## Запуск проекта: ##

### Выполнить команду для запуска парсинга вакансий: ### 
python main.py

### Выполнить команду для получения средней зарплаты и вакансий с выше средней зарплатой: ###
python main.py -h
